THE BROWN PRINT / DESIGN EXPLORATION

One project.
Two design approaches.

The same goal in both designs: introduce a personal newsletter and make joining simple. Each explores a different layout, reading flow and visual style.

EDITORIAL DESIGN

An editorial approach.

A split hero, warm cream surfaces and a strong typographic hierarchy give the newsletter a magazine-inspired introduction.

Focus: grid layout, storytelling, responsive columns and form feedback.

STACKED DESIGN

A focused vertical flow.

A full-width cover, dark brown surfaces and a centred signup card guide visitors through the story in a single column.

Focus: spacing, contrast, accessible fields and a consistent thank-you page.

Both public demos validate sample input without creating subscriptions or sending email. Stacked Design also includes a separate local Node.js/Express backend and newsletter dashboard; live email delivery requires configuration and testing.
